# Alex Siebenaler — Honors Portfolio

Live site: https://alexsiebenaler.github.io

Static site for the Minnesota State Mankato Honors Program.

- Edit content in `build.py`, then run `python3 build.py` to regenerate the HTML pages.
- Each experience has its own page (e.g. `ibe.html`), generated from the `COMPETENCIES` list in `build.py`.
- Put PDFs (essays, reflections, artifacts) in `docs/` and set the matching path in `build.py`.
- Put photos in `images/`.
